## 3. Проверка свидетельств, assessment B

- 39/39 файлов manifest существуют; SHA-256 и byte sizes совпадают с оригиналами.
- Итого 931 051 380 bytes: 17 фото, 17 видео, 3 референса, 1 logo, 1 PDF.
- Размеры всех изображений сверены Pillow; logo RGBA, alpha-bounds `(172, 694, 1712, 1359)` при canvas 2000×2000.
- 17/17 видеозаписей независимо сверены ffprobe: dimensions, codec, duration и audio stream. У V10 HEVC — для веба запланирована совместимая производная, не переименование MOV в MP4.
- PDF содержит 6 страниц; стр. 6 имеет ровно два используемых URL — Instagram и Spotify. Происхождение URL проверено, актуальность аккаунтов не доказана.

Assessment B нашёл конфликт между требованием доступности без JS и обычным client-only React SPA. Исправлено: базовая рекомендация Astro static + React islands, критические тексты статическим HTML, production QA с выключенным JS. Стек по-прежнему не выбран пользователем.

## 4. Slop-проверка и detector

Один реальный запуск `impeccable.cmd detect --json <project-root>`: exit code 0, результат `[]`, 0 findings. В проекте **0 markup files**, отдельную статистику покрытия detector не выдал. Это **не UI-pass** и не доказательство визуального качества. Повторно сканер не запускался.

Ручная проверка спецификации:

- Нет generic SaaS-bento, фиктивных counters, отзывов, рейтингов или логотипов партнёров.
- Hero основан на реальных людях и конкретном фото, а не абстрактном gradient blob.
- Основная галерея задана брифом; остальные эффекты не собраны в один конкурирующий экран.
- Отсутствуют обязательные random glass wrappers и двойные оболочки вокруг всех фотографий.
- Разные блоки имеют разные композиции и motion-роли; один reveal не размножается на всю страницу.
- Не закреплены бессодержательные пины, ненужный smooth-scroll и прелоадер с ожиданием.
- Читаемый EN copy и доступность не подчинены декоративной анимации.

Taste draw использован для исследования композиции, а не для отмены референсов. Причины отклонения несовместимых слотов записаны в DESIGN.md. Локальная коллекция awesome-design-md прочитана; копирования чужой системы и ложного заявления об установленной команде нет.
