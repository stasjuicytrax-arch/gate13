## Порядок внедрения на следующем этапе

1. Утвердить направление/стек и получить исходник обязательной галереи через официальный доступ.
2. Сначала создать статическую композицию с настоящими изображениями, текстом и booking-путём.
3. Добавить Gallery; проверить 390/1440px, touch, keyboard, reduce, seam бесконечного цикла и lightbox.
4. Добавить Hero timeline, затем локальные переходы. Папки — при наличии готовых downloads.
5. Только по итогам замеров пробовать halftone или haze. Не ставить все эффекты одновременно.
6. Если полный source галереи недоступен, сообщить об этом до реализации блока: не выдавать собственный похожий компонент за оригинал. Согласовать получение source или самостоятельную реализацию по его визуальной механике с явным указанием происхождения.
